# Environment Probe

A standardized diagnostic CLI package built with Python 3.12+ to inspect and verify runtime environments and configuration state.

---

## 1. Fresh Clone & Environment Setup

Follow these steps from an empty directory to clone the repository, isolate the environment, and install dependencies:

```bash
# 1. Clone the repository and navigate into the project directory
git clone https://github.com/yuwa619/environment-probe
cd environment-probe

# 2. Synchronize virtual environment and dependencies using uv
uv sync
